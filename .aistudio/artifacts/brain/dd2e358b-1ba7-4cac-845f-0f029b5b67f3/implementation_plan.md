# JARVIS Windows Edition: Cyber-HUD & Native Controller

Комплексный план адаптации веб-интерфейса Jarvis под Windows: превращение веб-HUD в специализированный пульт прямого управления операционной системой с поддержкой голосовых команд, распознавания жестов с веб-камеры и каталогом запуска приложений, веб-сервисов и ИИ-ассистентов.

### User Review & Critical Decisions

> [!IMPORTANT]
> На основе ответов пользователя зафиксированы следующие ключевые решения:
> - **Связь с Windows**: Прямой клиент к локальному Windows-агенту (Python HTTP Bridge `http://127.0.0.1:8765`), транслирующий команды на компьютер пользователя, со встроенным индикатором статуса соединения и скриптом-компаньоном с поддержкой CORS.
> - **Управление жестами**: Встроенное в веб-интерфейс распознавание жестов руки через браузерную веб-камеру с визуализацией скелета руки и распознанных поз (ладонь, кулак, победа/V, указательный палец, большой палец) плюс отправка сигналов управления в Windows.
> - **Приоритет команд**: Фокус на запуске локальных приложений Windows (Telegram, Steam, OBS, Chrome, Discord, Калькулятор, Блокнот, Проводник, Диспетчер задач, Терминал), веб-сервисов (VK, Яндекс Музыка, Кинопоиск, Wildberries, Ozon, Avito, GitHub) и ИИ-платформ (ChatGPT, DeepSeek, Claude, Google/YouTube Search).

### 1. Overview & Core Concept

- **Что делает приложение**: Полноэкранный кибернетический HUD в стиле Iron Man Jarvis, обеспечивающий сквозное голосовое и жестовое управление компьютером под управлением Windows. Пользователь может отдавать голосовые команды (через Web Speech API или офлайн-микрофон агента), показывать жесты на веб-камеру или нажимать быстрые кнопки на панели управления.
- **Целевая аудитория**: Пользователи Windows, которым нужен быстрый, футуристичный и удобный голосовой/жестовый ассистент для мгновенного запуска любимых программ, ИИ-инструментов и мультимедиа без лишних кликов.
- **Ключевая ценность**: Объединение визуального совершенства веб-HUD (Voice Orb, телеметрия, логи, терминал) с реальной мощью Windows API (локальный запуск процессов, переключение задач, браузерные протоколы).

### 2. User Experience & Visual Design

- **Ключевые пользовательские сценарии**:
  1. *Мониторинг связи*: В шапке отображается статус Windows Agent (`ONLINE` / `CONNECTING` / `DISCONNECTED`). При отсутствии запущенного агента выводится аккуратное окно подсказки с возможностью в один клик скачать или скопировать готовый python-скрипт `jarvis_bridge.py` и батник запуска.
  2. *Голосовое управление*: Пользователь нажимает на Voice Orb или произносит активационную фразу «Джарвис» (или отдаёт команду напрямую). Голос распознаётся, шар начинает пульсировать в такт звуковой волне, ассистент отвечает голосом и мгновенно отправляет команду на исполнение в Windows.
  3. *Жестовая панель*: Окно камеры в правом нижнем/верхнем углу (с возможностью свернуть/развернуть). Распознаёт жесты в реальном времени:
     - `Open Palm` (Открытая ладонь) — подтверждение / развернуть окно / вызов Jarvis
     - `Victory (V)` — переход / следующий сервис / прокрутка
     - `Fist` (Кулак) — пауза / свернуть / отмена
     - `Point` (Указательный палец) — выбор приложения
     - `Thumb Up` (Большой палец вверх) — запуск приоритетного приложения (Telegram/Браузер)
  4. *Каталог запуска (Приложения, Сайты, ИИ)*: Интерактивная командная панель со вкладками:
     - **Windows Софт**: Telegram, Steam, OBS Studio, Discord, Google Chrome, Терминал PowerShell, Диспетчер задач, Проводник, Калькулятор, Блокнот, Камера, Paint.
     - **Сайты и Сервисы**: YouTube, Яндекс Музыка, Кинопоиск, VKontakte, GitHub, Wildberries, Ozon, Avito.
     - **ИИ-сервисы**: ChatGPT, DeepSeek, Claude, Быстрый поиск в Google и YouTube.
     - **Пользовательские команды**: Возможность добавить свой путь к `.exe` или URL с пользовательской голосовой триггер-фразой.

- **Визуальная айдентика и тема**:
  - *Эстетическое направление*: Sci-Fi Cybernetic Iron Man HUD, глубокая космическая обсидиановая гамма (`#050B14`, `#07111F`) с лазерным неоновым цианом (`#29D8FF`, `#00E5FF`) и глубоким синим кобальтом.
  - *Цветовая палитра*: 60% фон `#050B14`, 30% структурные панели `#0B1726` с тонкими границами `rgba(41,216,255,0.18)`, 10% акцентное неоновое свечение и реактивные волны.
  - *Типографика*: Чистый технологичный гротеск (`Plus Jakarta Sans` / `Segoe UI`) для интерфейса и четкий моноширинный шрифт (`font-mono tabular-nums`) для таймеров, логов выполнения и статусов порта.
  - *Voice Orb*: 3D-анимированная сфера из частиц на HTML5 Canvas с реакцией на фазы: `Ожидание` (медленное вращение синих частиц), `Слушаю` (яркое бирюзовое пульсирующее кольцо), `Обработка` (ускоренный вихрь частиц), `Ответ` (волновые колебания).

### 3. Key Product Decisions & Trade-Offs

- **Прямое взаимодействие с Windows через Local Bridge (`127.0.0.1:8765`)**:
  - *Подход*: Веб-приложение отправляет HTTP POST `/command` на локальный Python-демон. В интерфейс интегрирован мастер подключения с диагностикой и встроенный генератор `jarvis_bridge.py`, где настроены `CORS`, запуск приложений через `subprocess` и `startfile`.
  - *Почему*: Браузерная песочница по соображениям безопасности не может напрямую вызывать произвольные бинарники Windows (`calc.exe`, `Telegram.exe`) без локального процесса. Предоставление бесшовного моста даёт 100% реальное управление Windows.
- **Встроенное распознавание жестов на Web-Canvas / MediaPipe**:
  - *Подход*: Использование браузерного API веб-камеры с легковесным распознаванием контуров и ключевых точек руки (пальцы/ладонь/кулак) прямо в React, с визуальной подсветкой и триггером команд.
  - *Почему*: Работает плавно с нулевой задержкой отображения в браузере и не требует отдельной установки тяжелых Python GUI зависимостей для предпросмотра камеры.
- **Фокус на запуске софта, сайтов и нейросетей**:
  - *Подход*: Полная структурированная библиотека команд разбита по категориям с быстрыми чипами запуска и мгновенным голосовым синонимами (например, для Telegram: «телеграм», «телегу», «тг», «telegram»).

- **Основные модули**:
  - `src/types/jarvis.ts`: Типы команд, категорий (apps, web, ai, custom), событий журнала и статусов агента.
  - `src/lib/windowsCommands.ts`: Полная база команд из `jarvis_unlocked.py` с ключевыми словами, путями к приложениям и URL.
  - `src/lib/agentClient.ts`: Драйвер связи с локальным агентом Windows (`fetch` с проверкой здоровья `/ping`, отправкой `/command`, автопереподключением).
  - `src/components/VoiceOrb.tsx`: Оптимизированный холст с частицами (520 частиц в 3D-сфере, светящийся градиент, пульсация).
  - `src/components/GestureRecognition.tsx`: Браузерное распознавание жестов руки через `getUserMedia` и обработчик видеокадров с определением жестов (V/победа, кулак, открытая ладонь, палец вверх).
  - `src/components/CommandCatalog.tsx`: Вкладки по категориям (Софт Windows, Сайты и Сервисы, ИИ-платформы, Свои команды) с кнопками немедленного запуска.
  - `src/components/WindowsAgentModal.tsx`: Интерактивное руководство и скачивание готового файла `jarvis_bridge.py` и `start.bat`.
  - `src/components/ActivityLog.tsx`: Терминал логов с подсветкой статуса выполнения на Windows.

### 5. Verification Plan

- **Сборка приложения**: Проверка сборки `npm run build` с помощью инструмента `compile_applet`.
- **Проверка компонентов**:
  1. Тестирование Voice Orb и анимаций Canvas.
  2. Тестирование голосового распознавания речи (Web Speech API с голосовыми ответами синтезатора).
  3. Тестирование модуля жестов веб-камеры (включение камеры, распознавание жестов, отправка событий).
  4. Проверка корректной генерации кода `jarvis_bridge.py` со всеми командами и заголовками `Access-Control-Allow-Origin: *`.
  5. Проверка кликабельности и выполнения команд приложений, сайтов и ИИ-сервисов.
